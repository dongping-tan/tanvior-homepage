# Tanvior

将目标、时间安排、日历和完成进度放在同一个页面的本地优先 MVP。依据 `Tanvior.xlsx` 第一阶段实现，使用 HTML、CSS 和原生 JavaScript；无需构建、账户、API 密钥或运行时依赖。

## 本地运行

```sh
cd /workspace/tanvior-homepage  # 或你的仓库目录
python3 -m http.server 8000 --bind 0.0.0.0
```

在本地开发机器上打开服务的首页。开发服务仅用于开发，不是生产部署服务器。

## 使用

1. 点击进入介绍页，或等待 15 秒自动进入工作台。
2. 新建任务，填写名称、开始/结束日期、目标和当前状态，勾选每周可用时间。
3. 可展开微调，选择一个或多个具体日期，批量添加或移除相应时间块。
4. 生成计划后在卡片或今日面板填写 0–100 的整数完成百分比。任务进度与日历颜色同步；点击日历安排可突出对应任务卡。
5. 可标记、删除任务，桌面端拖动卡片标题调整位置。支持中文、英语、日语、西班牙语、法语、韩语界面；用户输入和已生成计划正文保留原语言。
6. 任务卡可以导出，点击日历标题/月名可打开月度详表并选择月份导出。侧栏可导出/导入全量 JSON 备份。

**规划能力：** 当前“智能生成”是本地规则：按选中的时间块，依序划分基础、实践、复盘验收阶段；每块一小时，不进行能力评估、不调用真实 AI、不保证目标达成。同一时间的不同目标允许重叠，创建时提示冲突。

**数据：** 使用 `localStorage` 的 `tanvior.workspace.v1` 保存，含任务、逐次完成度、卡片位置和界面语言。只保存在当前浏览器/站点，不跨设备同步。清理浏览器数据将删除记录，请定期备份。JSON 备份包含所有目标及当前状态描述，请自行妥善保管。导入经过结构校验并要求确认后替换。旧版的 `goal` / `targetDate` / `availableTimes` 不会自动导入或删除，因为它们缺少完整计划数据。

**导出格式：** PDF 通过浏览器“打印 → 保存为 PDF”；Word 是 HTML 兼容 `.doc`；Excel 是 SpreadsheetML 2003 XML `.xls`。不是原生 `.docx` / `.xlsx`，部分 Office 版本可能显示格式兼容提示。月度表包含该月所有任务的时间块。JSON 备份始终包含完整工作台，支持恢复。导出采用 XML/HTML 转义及字符串单元格，避免用户输入被当作标记或公式。

## 检查

排程单元测试（仅需 Node.js 18+，本次在 Node 24 验证）：

```sh
node --test tests/*.test.js
node --check app.js
node --check planner.js
node --check i18n.js
```

真实浏览器检查需 Python Playwright 与 Chromium；可使用已安装的系统 Chromium，无需额外下载：

```sh
# 在已有 Python Playwright 的环境中执行
python3 -m http.server 8001 --bind 0.0.0.0
# 另一终端执行；默认寻找系统 chromium
python3 tests/browser_smoke.py http://127.0.0.1:8001
# 必要时通过 CHROMIUM_PATH 指定浏览器可执行文件
```

测试涵盖任务生成、具体日期覆盖、进度与持久化、标记/删除、日历、拖动、语言、文件导出与 PDF、备份恢复、损坏存储保护、移动布局、介绍页计时和旧链接兼容。截图输出至 `/tmp/tanvior-desktop.png` 和 `/tmp/tanvior-mobile.png`，不提交生成文件。

详见 [需求对照与后续阶段](docs/requirements.md)。

## 访问统计（Umami Cloud）

生产首页加载 Umami 官方脚本 `https://cloud.umami.is/script.js`，使用公开 Website ID `be54261d-7a2b-4a9a-8414-2f820fb9a4b1`。`data-domains` 允许 `dongping-tan.github.io`、`www.tanvior.com` 和 `tanvior.com`，避免正常的 localhost 开发访问进入生产统计。GitHub Pages 域名下其他项目只有安装了同一脚本才会上报。正式域名与 GitHub Pages 共用一个 Website ID；在 Umami 中可按主机名和路径区分访问。

在 Umami Cloud 登录自己的账号，打开 Tanvior 网站统计，选择 **Today / 今天**，查看 **Visitors / 访客** 与 **Views / 浏览次数**。按需检查后台时区；日本自然日应选择 `Asia/Tokyo`（或后台相应时区设置）。访客是统计服务的估算，不等于精确自然人数，广告拦截器和网络故障可能造成漏计；新接入前的历史访问无法补回。

本次仅接入标准页面访问统计，不添加自定义事件、不把任务名称、目标、现状、计划、备份或 localStorage 内容发送给 Umami。标准脚本仍会处理页面访问相关元数据，避免在 URL 或页面标题中放置敏感内容。访问提示已同步更新中英文。统计脚本不可用时，规划功能仍可独立使用。

Website ID 是公开站点标识，不是后台登录凭据。账号密码与私密 API 密钥不应写入仓库。当前尚未实现网站内私人管理页：GitHub Pages 无法提供服务端登录保护，且当前免费套餐的私人统计 API 能力未确认。请先使用 Umami 账号保护的后台；不将统计面板公开分享或嵌入以替代访问保护。

## 首次访问语言选择

右上角地球图标旁可随时选择中文、English、日本語、Español、Français、한국어。手动选择、已有工作台保存的语言以及导入备份的语言优先，之后访问不会重新按 IP 改写。旧版中英文备份仍兼容。

首次访问且尚无保存设置时，先按浏览器语言展示，同时通过 HTTPS `https://api.country.is/` 查询 IP 所在国家，最长等待 2 秒。成功则选择该国家对应的支持语言；失败、限流、无效返回或未知国家时采用浏览器支持语言，均不支持时采用英语。美国、英国、澳大利亚等使用英语，日本使用日语，韩国使用韩语，中国等使用中文，西班牙及主要西语国家使用西班牙语，法国等使用法语。加拿大等多语言国家在其支持语言中参考浏览器偏好。IP 只是地区估算，VPN/代理可能改变结果。

该请求不附带凭据、Referrer 或任务数据；外部服务会自然接收到访问者的网络 IP。应用只使用返回的国家代码，不存储 IP。采用公开、无需密钥的国家查询服务，无可用性保证；服务不可用不阻止使用，且手动选择始终优先于延迟到达的查询结果。更换浏览器、站点域名或清空存储会视为新的访问环境。首次推荐语言与手动选择均保存在该站点的 localStorage。

所有界面、表单、日期、星期、规划阶段和导出表头支持六种语言。用户输入及已生成计划正文保留原文，不自动翻译。可执行 `python3 tests/language_browser.py http://127.0.0.1:8004`（先启动对应端口服务）验证六国语言、移动布局、手动选择优先、保存和网络失败回退。测试模拟国家查询并拦截 Umami，不向生产统计发送测试访问；不代表已验证第三方服务真实联网结果。
